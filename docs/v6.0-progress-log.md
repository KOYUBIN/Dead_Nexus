## 핵심 발견 (밸런스)
- 원 과제 지목 이슈는 **이미 해소**: CARBON 11×11 0%→30%(v5.2.2), CIPHER 5×5 0%→44%(v5.2.3), 5×5 견제 너프 완료(1.1회/판).
- N=200에서 보이던 "DRIFTER 75% / MOLE 0% 폭주"는 **표본 노이즈** (클래스당 16~20판). N=600에선 전 클래스 임계 내.
- **유일한 구조적 약점**: RIGGER는 클래스 중 유일하게 applyClassSignatures에 항목이 없었고 양 모드 최저(11×11 20% / 5×5 12%).
  → `euro_riggerSignature` 신규(자동 함정망: 매R ⚙+1, 함정 3개마다 ★+2). 결과 RIGGER 38%/34%로 정상화, 11×11 Ghost 진영 42%→51% 동반 개선.
- 노이즈 과적합 회피: N=600 임계 내인 AXIOM/BROKER/DRIFTER는 추가 너프 보류.

## 최종 200판 측정 (`balance_test.js`)
- **11×11**: Ghost 48.5% / Bloc 51.5% · 평균 10R · RIGGER 35.3%. (BROKER 64.7%는 17표본 노이즈, N=600서 54%)
- **5×5**: Ghost 51.5% / Bloc 48.5% · 평균 7R · RIGGER 41.2%. (AXIOM 60%는 20표본 노이즈, N=600서 43%)
- 진영 균형은 양 모드 모두 안정. N=600 반복 시 전 클래스 임계 내 확인.

## 실행/검증 명령 (sim-harness/)
```
npm test              # 200판 11×11
npm run test:5x5      # 200판 5×5
npm run test:both     # 11×11 + 5×5 종합
npm run test:full     # 600판 11×11 (저노이즈)
npm run test:seed     # 결정론(회귀 동일성 검증)
npm run trace         # 발동 타임라인 (AXIOM 예시)
npm run test:decisions # 결정 모달 골격 자기검증 (11/11)
node balance_test.js --trace 11x11 ghost RIGGER 7   # RIGGER 함정 발동 추적
```
