## 0. 개요

### 0.1 연구 질문과 방법

- **질문**: `docs/21-design-research.md`(기계적 감사)가 "무엇이 고장났는가"를 다뤘다면, 이 보고서는 **"이 게임은 무엇이 되어야 하는가"** 를 다룬다. 두 보고서는 의도적으로 비중복이다.
- **방법**: 4개 관점 병렬 연구 — ① 정체성 진단(문서 약속 vs 실물), ② 플레이어 경험·판타지, ③ 장르 검증 메커니즘 차용(Root · Netrunner · Brass · Gloomhaven · Pandemic Legacy · BGA/디지털), ④ 게임성 역학(긴장·인터랙션·리플레이) — 그리고 4개 결과에 대한 종합 판정.
- **실측 기준선**: E2E 20판(11×11, `sim-e2e/results/2026-07-14T01-37-27-251Z.json`) — ghost 45% / bloc 55%, 평균 7.05R, 견제 1.8회/판, M&A 선언 0회(32판 누적), 봇 지분 상한 29%. 근거가 약한 항목은 **(추정)** 으로 표기했다.

### 0.2 핵심 결론 (3줄)

1. **이 프로젝트는 이미 디지털 게임이다** — "보드게임의 프로토타입"이라는 자기 서사는 대면 플레이테스트 0회, 시뮬 발명→문서 사후 추인이라는 역방향 흐름, 수기 운영 불가 규칙의 축적 앞에서 성립하지 않으며, 정체성 결정을 미루는 비용(3원장 드리프트, 죽은 시스템)은 이미 계상되고 있다.
2. **권장 정체성**: "혼자 30~60분, 개성 있는 봇 3과 겨루는 사이버펑크 비대칭 시장 전쟁 — 레이드(폭력·정보)가 곧 주가 포지션이 되고, 판의 결과가 다음 판의 도시에 흉터로 남는 솔로 우선 유로 웹게임" (후보 A 몸통 + 니치 기함 루프 + 후보 C 경량 레거시 아크의 합성).
3. **선행 조건은 레이스의 정직화다** — 승부가 착석 구성으로 19/20 결정되고 계기판(진척 바·위협 배지)이 3중 불일치 임계값으로 거짓말하는 동안에는 어떤 판타지·레거시 투자도 체감되지 않는다. P0는 계기판 정직화 + 상호작용 각성(M&A·리더 브레이크) + 니치 선언(공매도)에 집중한다.

## 1. 현 정체성 진단 — 문서 약속 vs 구현 현실

### 1.1 두 개의 게임

`docs/00-overview.md`는 "2–5인 · 120–180분 테이블탑 레거시 보드게임"을 약속하지만, 실제 살아있는 산출물은 **1인+봇3 웹 전략 게임**이다.

| 증거 | 내용 |
|---|---|
| 대면 플레이테스트 0회 | `playtesting/`에 session-00 가이드 1개뿐, README 로드맵에서 "대면 플레이테스트 1~3회"는 아직 미래 항목(v2.0+) |
| 투자 방향 | CHANGELOG 70여 릴리스 중 v0.5.1(솔로 시뮬레이터 MVP, 2026-04-22) 이후 대부분이 시뮬레이터·봇 AI·밸런스 회귀(N=600 harness, E2E 20판)에 집중 |
| 정본 역전 | 개인 속성 풀(공용 풀 v0.5.3 폐기), 결정론 레이드(v5.0.0 "유로 전환" — 브라스 버밍엄/뉴클리엄 명시 인용), EV-중립 결정 모달(3★≡₵4+⚙2), suppressionProb 0.30, grudge AI — 컴퓨터 없이 운영 불가한 규칙이 시뮬에서 먼저 태어나고 docs/02가 "시뮬레이터 플레이테스트 결과 핵심 룰 확정"이라 사후 추인 |
| 보드게임 자산 정체 | 레거시 8챕터는 완결 집필됐으나 웹 구현 0% · 세이브 인프라 부재, print-kit는 뉴스 15장 vs 웹 40장으로 사실상 다른 게임(docs/21의 3원장 드리프트) |
| 표기 괴리 | README "60–90분"은 E2E 평균 7.05R 실측 대비 과대 추정 |

**판정**: '보드게임의 디지털 프로토타입'이 아니라 **'보드게임 문서를 가진 디지털 게임'** 이다. 프로토타입이라면 검증 결과가 테이블 룰로 환류돼야 하는데 흐름은 역방향이고 테이블 검증은 0회다. 결정적 증거는 '기계 전용 규칙'의 축적 — 매R 자동 발동 시그니처 13종, 확률적 봇 견제(R당 0.30)와 보복 메모리, EV-중립 환산 공식, 개인 풀 절반 감쇠+반올림 — 어느 것도 수기 운영이 불가능하다. 인원(2–5 → 1–5) · 시간(120–180 → 60–90 → 실측 ~7R)의 변천사가 같은 방향을 가리킨다. "보드게임의 프로토타입"이라는 자기 서사는 정체성 결정을 미루는 알리바이로 기능하며, 그 유예 비용은 죽은 시스템(레거시 웹 0%, M&A 봇 휴면, 핫시트 저활용)과 문서 드리프트로 이미 지불되고 있다.

### 1.2 참조 게임 충돌 — 5종 레퍼런스, 3개의 양립 불가 세션 형태

| 계열 | 참조 | 약속하는 세션 | 웹 구현 현실 |
|---|---|---|---|
| (a) 캠페인 소모전 | 글룸헤이븐, 메이지나이트 | 손패 소모전 퍼즐 + 캠페인 | 휴식/상처/스캔들(손패 시계) 미구현 |
| (b) 테이블 정치 | Root | 다인 테이블 정치로만 균형 잡히는 비대칭 | 정치 대신 기계적 패리티 패치(GhostHustle 등)로 대체 |
| (c) 엔진 빌딩 유로 | MTG 비용계 + TM 마일스톤(v3.1) · 갤러리스트 건물(v0.6.3c) · 브라스/뉴클리엄 결정론(v5.0.0) | 결정론 엔진 빌딩 | **코드가 이미 택한 노선** — 공용 마나 풀은 v0.5.3 폐기 |

코드는 이미 (c)를 택했다. 버려야 할 것의 1순위는 Root식 테이블 정치와 물리 레거시 봉투이고, 지킬 것은 비대칭 구도 · 유로 결정론 · 캠페인 서사(단, 디지털 매체로)다.

## 2. 정체성 후보들과 판정

### 2.1 후보 4종

| 후보 | 정의 | 코드와의 거리 | 핵심 병목 |
|---|---|---|---|
| **A. 솔로 우선 봇 대전 유로 웹게임** | 혼자 30~60분, 개성 있는 봇 3과 겨루는 사이버펑크 비대칭 유로 전략 | **최단(~90% 존재)** | 봇 품질(M&A 휴면, 무명·무성격), 판마다의 변주(시나리오 S01뿐) |
| **B. 테이블탑 디지털 트윈** | 정본은 룰북, 웹 시뮬은 검증 도구인 3~5인 120분 테이블 게임 | **최장** | 시뮬 태생 규칙 ~20개 역이식 + 대면 테스트 0회 관문 |
| **C. 디지털 레거시 캠페인** | 선택이 저장되고 도시가 영구히 변하는 8챕터 캠페인 웹게임 | 중간 | 콘텐츠 자산 최상(8챕터·4엔딩·인물 11인, 전부 웹 노출 0%)이나 세이브 인프라 0 |
| **D. 핫시트/대전 정치 게임** | 2~5인 한 화면 비대칭 권력 정치전(협상·견제·M&A) | 중간 | 협상이 스왑/휴전뿐 + 반복 가능한 인간 그룹이라는 외부 제약 |

### 2.2 권장안 — A 몸통 + 니치 기함 + C 아크의 합성

> **"혼자 30~60분, 개성 있는 봇 3과 겨루는 사이버펑크 비대칭 시장 전쟁 — 레이드(폭력·정보)가 곧 주가 포지션이 되고, 판의 결과가 다음 판의 도시에 흉터로 남는 솔로 우선 유로 웹게임."**

핵심 세션 경험: 역할·시나리오 선택 → 정직한 레이스 계기판 아래 7R의 결정 밀도(레이드 심도 · 숏 포지션 · 확장 택1 · 견제) → 전원이 지켜보는 종료 선언 라운드 → 하이라이트 릴 착지 → 상흔이 다음 판 도시에 각인.

**논증 (4기준)**:

1. **코드 자산과의 거리**: A는 최단 — 살아있는 자산(레이드 6타입 모달, 주가/시장 사이클, 견제·grudge AI, pendingDecisions 큐, 시드 결정론, Vercel 배포)이 이미 A의 대부분이다. B는 최장 — 기계 전용 규칙의 역이식 + 대면 테스트 0회라는 이중 관문.
2. **1인 개발 지속성**: B·D는 '반복 가능한 인간 그룹'이라는 외부 자원을 요구하는데, `playtesting/`에 session-00 가이드 1개뿐(실행 0회)이라는 실적이 그 자원의 부재를 증명한다. A는 봇이 상대라 개발=테스트다.
3. **세션 차별성**: A 단독("솔로 봇 유로 웹게임")은 범용 카테고리라 그 자체로는 기각 사유다. 차별성은 장르 지형의 빈 니치 **'사이버펑크 + 비대칭 + 살아있는 주식 시장'** 에서 온다 — Netrunner는 1v1·시장 없음, Root는 경제 없음, Brass는 직접 공격 없음, New Angeles는 준협력. 레이드 성공=주가 -3이 이미 코드에 있으므로 공매도 규칙 하나로 니치가 실증된다. `docs/08` §7의 "CIPHER 주가 조작 후 매수"가 이미 이 방향을 예언한다.
4. **니치 비겹침**: 부차로 '봇 동반 솔로 사이버펑크 전략'(Netrunner엔 공식 솔로 없음)도 이미 절반쯤 점유 중이다.

**트레이드오프 (명시)**:
- 테이블 패리티를 버리면 3원장 드리프트·이중 유지보수가 끝나는 대신 '보드게임' 자기 서사와 print-kit 투자가 상각된다 — 검증 0회 가설을 유지하는 비용이 더 크다(드리프트 비용은 docs/21이 이미 계상).
- 8챕터 일괄 웹화를 미루면 최대 콘텐츠 자산의 상각이 늦어지는 대신, 상흔/시즌(M급)으로 '레거시' 이름값의 수요를 먼저 싸게 검증하고 세이브 인프라(docs/21 P2 계열)와 순서를 맞출 수 있다.
- E2E 실측(구성 결정론 19/20, R5 댐 8/20, highlightPoints 소비처 0, 가짜 임계값 55/16)이 "무엇을 먼저 고쳐야 정체성이 성립하는가"를 지시한다 — 계기판이 거짓말하는 동안에는 어떤 판타지 투자도 체감되지 않는다.

### 2.3 기각안과 이유

| 기각 대상 | 이유 | 처분 |
|---|---|---|
| **B. 테이블탑 디지털 트윈** | 코드 거리 최장 + 외부 자원(대면 그룹) 의존. 시뮬 태생 규칙 ~20개(자동 시그니처 13종, 확률 봇 견제 0.30, EV-중립 공식, 개인 풀 감쇠)는 수기 운영 불가라 역이식이 사실상 재설계이고, 대면 테스트 0회 실적이 관문 통과 가능성을 부정 | print-kit은 컴패니언 굿즈로 강등, 유지보수 대상 제외. "존폐 관문 1회 실측"(L급) 실험도 함께 기각 — 정체성을 지금 결정하면 관문 실험이 불필요해지고, 그 L을 니치 기함에 쓰는 것이 낫다 |
| **C 단독 몸통 (레거시 캠페인 우선)** | 콘텐츠 자산은 최대지만 세이브 인프라 0(localStorage는 전적 50판 기록뿐) · 챕터당 L급 비용 · 1인 개발에서 콘텐츠 소모형 로드맵은 지속 불가 | 완전 기각이 아니라 **아크로 흡수** — 상흔/시즌(M)으로 수요 검증 후 챕터 1만 P2로. 8챕터 일괄 웹화는 non-goal |
| **D. 핫시트 정치 게임** | B와 동일한 외부 제약 + 1기기 핫시트는 은닉 정보·자유 협상(정치 게임의 본체)과 구조적 충돌 | "지원되지만 설계 대상 아님" — 셸은 유지, 신규 투자는 담보 에스크로 딜 1건(P2)이 상한 |
| **A 단독 (순수 현 상태 공식화)** | 코드 거리 최단이지만 차별성 미달 — 범용 카테고리라 참조 게임들의 디지털판과 정면 경쟁. 니치 기함(시장×폭력 루프)과 경량 레거시 없이는 "왜 이 게임인가"에 답이 없다 | 단독 채택 대신 합성의 몸통으로만 채택 |

## 3. 플레이어 판타지와 감정 곡선

### 3.1 판타지 진단 — 문서는 선명하고 배달은 반쪽이다

| 진영 | 문서가 파는 꿈 | 웹의 배달 현실 |
|---|---|---|
| **Ghost** | "시스템에 배신당한 개인의 복수 + 하이스트" (`docs/04` — 6인 전원이 특정 블록에게 배신당한 서사) | 인간 레이드는 접근→실행→도주 3단계 + 투자 + 성공률 공개로 하이스트 골격을 갖췄으나(`index.html:5627~5795`) **3판정이 1클릭 일괄 로그로 끝나 비트(beat)가 없고**, 성공 보상 선택은 의도적 EV-중립(v6.6)이라 클라이맥스가 장부 처리다. 수배·공권력은 소비처가 뇌물 해금뿐인 죽은 게이지(`:2395`) — '쫓기는 생존' 판타지 미배달 |
| **Bloc** | "기업 마키아벨리즘 — 정보전·시장조작·M&A" (`docs/03`) | 핵심 성장엔진인 영향권 확장(+5자산)이 **랜덤 자동**(`:3021~3048`), 대표 모달 bloc_invest는 설계상 점수-중립(v6.8), M&A 방어 모달은 봇 휴면으로 발동 0회 — '지켜보는 경영' |

핵심 발견 3가지:

1. **Ghost 판타지의 정체는 '하이스트'가 아니라 '복수'다** — docs/04의 6인 전원이 특정 블록 배신 서사(STATIC↔VANTA, RUST↔IRONWALL, FLINT↔CARBON, ECHO↔HELIX, PATCH↔AXIOM)를 갖는데, 게임에는 이 개인적 원한을 표현할 장치가 상성 +1(countersBloc) 하나뿐이다. 내 원수 블록을 쳐도 게임은 아무 말도 하지 않는다.
2. **이 게임에서 이미 가장 잘 만든 순간은 인간 레이드 모달이다** — 문제는 해상도가 아니라 '연출 시간': 3개의 주사위가 한 클릭에 동시 공개돼 계획(1분)과 결과(0초)의 비대칭이 카타르시스를 증발시킨다. 신규 시스템보다 이 순간에 투자하는 것이 ROI가 가장 높다. (추정 — 정성 판단이나, 하이스트 장르 문법과의 대조에 근거)
3. **Bloc의 유일한 살아있는 마키아벨리즘 루트**(직접 라이벌 지분 51% 매집 → DECLARE_MNA)를 UI가 전혀 홍보하지 않는다.

### 3.2 세션 감정 곡선 — '댐 구조'

- R1~4는 승리 판정 자체가 돌지 않고(5R 최소 라운드 가드, `index.html:4939`), **E2E 20판 중 8판이 정확히 R5에 종료**, 승자 자산 96~120(게이트 95) 오버슈트. 즉 승부는 R3~4에 결정되고 플레이어는 그 사실을 모른 채 2라운드를 더 본 뒤 '결산 공지'로 끝을 통보받는다. 살아남은 12판은 R7~12 소모전.
- **계기판 3중 불일치**: 진척 UI·튜토리얼은 렙16/자산55 기준(`:6014~6029`, `tutorial_module.js:68~71`), 실게이트는 5×5 70/42/60 · 11×11 95/45/70(`:4947~4949`), MAP_RULES엔 제3의 값 — R3쯤이면 봇들에게 🏆 배지가 붙은 채 게임이 계속되는, 늑대 소년이 된 계기판이다. docs/21의 기계 감사에 없는 경험 계층의 최우선 결함.
- **봇 3명은 '위협 게이지가 달린 날씨'다** — 존재감 채널(lastTargetedBy 배너, 보복 태그, 봇 거래 로그)은 있으나 전부 사후적·수동적이고 150줄 로그 캡에 묻히며, 봇은 의도를 사전에 방송하지 않고 인물(수장 5인·코드네임 6인)로 말하지 않는다. `docs/19` 표본 5종이 전부 '두 봇의 경주 관전 기록'으로 읽히는 것이 증거다.

### 3.3 자산은 창고에 있다

뉴스 35종 플레이버, 카드 플레이버 90+, 하이라이트 모먼트 12종, 협상/휴전 시스템, 명대사가 정의된 인물 11인 — 부족한 것은 콘텐츠가 아니라 이 자산을 **결정적 순간에, 인물의 목소리로** 표면화하는 배선이다.

## 5. 게임성 역학 보강 근거 — '평행 레이스' 실증

포트폴리오 우선순위의 근거가 되는 역학 실측 (E2E 20판 + 코드 재확인):

1. **구성 결정론 19/20** — 고스트 3석 판은 고스트 9/10 승, 블록 3석 판은 블록 10/10 승. 겉보기 45%/55% 균형은 구성 추첨의 평균일 뿐이며, 플레이는 '레이스 티켓 수' 싸움이다.
2. **견제 무력** — 견제 토큰 3종 자원(★/📡/🎙)은 assetValue(타사주식+구역×5+건물, `index.html:1477`)와 완전 직교 — 시스템에 '선두 블록을 늦출 수단'이 없다.
3. **결정 모달의 무게와 도달 빈도가 반비례** — 매판 뜨는 bloc_invest는 EV=0 설계(주석으로 자체 논증, `euro_module.js:758~761`), raid_reward는 기본값(rep)이 우월, 유일하게 무거운 mna_defense 4종은 봇 매집 한계(지분 상한 29%, BOT_MARKET `index.html:2594` 가격≤7 랜덤 매수)로 32판 0회 발동.
4. **write-only 통화** — 마일스톤(₵5)·어워드 펀딩(₵8~20)이 지불하는 highlightPoints는 index.html 소비처 0건(grep 확인) — 관련 모달 2종이 '₵를 내고 아무것도 얻지 않는' 미끼이고 봇도 같은 함정에 ₵를 태운다.
5. **고스트 봇 압력은 지리 기반** — findNearestBlocZone(`index.html:3433`)이 선두 무관 최근접 BFS라 먼 코너의 선두 블록이 무저항 독주한다.
6. **리플레이 분산원 부재** — 맵·HQ·고스트 시작점·덱 전부 고정, 솔로 구성 1v3 하드코딩(`index.html:1570~1574`). 반면 `docs/14` S02~S06은 정확히 '구성·시작조건 변주'로 완비돼 있는데 웹이 쓰지 않을 뿐이다.

## 7. Non-goals — 명시적 포기 목록

1. **물리 보드게임 정본화 · print-kit 패리티 유지** — 시뮬 태생 규칙의 수기 다운컴파일과 3원장 동기화를 중단하고 print-kit은 컴패니언 굿즈로 강등. "B 존폐 관문 실험"(L)도 함께 폐기 — 정체성 결정으로 관문이 불필요해짐.
2. **대면 플레이테스트를 출시·검증 조건으로 삼기** — 검증 정본은 sim-e2e · N=600 harness.
3. **8챕터 레거시의 일괄 웹화 및 Pandemic Legacy식 파괴적 영구화** — 시즌·상흔(경량)과 챕터 1 실험(P2)까지만.
4. **멀티플레이어 백엔드 · BGA식 비동기 서버** — 정적 페이지 아키텍처 유지, 온라인 대전 없음.
5. **핫시트(2~5인)의 설계 대상화** — "지원되지만 설계하지 않음", 신규 투자는 에스크로 딜 1건(P2-6)이 상한.
6. **Root식 진영별 완전 별개 룰북** — '공유 골격 + 시그니처 레이어'(현 euro_module 패턴)가 비대칭의 상한.
7. **자유 블러핑 · 자유 협상 · 손패 은닉 시스템** — 봇 레짐에서 불성립. 은닉은 토큰 단위, 선택은 만료 기본값 결정 큐로만.
8. **Brass식 폐쇄 경제 · 대출 시스템으로의 전면 개조** — 지대(배당·통행료) 부분 이식까지만.
9. **판 길이 확장** — 실측 평균 7R(30~60분)을 공식 세션 길이로 채택, README '60~90분' 표기를 실측에 맞춰 수정. 120~180분 게임으로의 회귀 없음.
10. **6~8인 확장 · TTS(Tabletop Simulator) 포팅 등 물리·대인원 파생물 일체**.

## 8. docs/21(기계 감사)과의 관계 — 우선순위 병합 제안

### 8.1 역할 분담

- **docs/21** = "고장난 것" — 판정 경로 버그, 죽은 시그니처, 3원장 드리프트, 표기·라벨 이식.
- **docs/22(본 문서)** = "되어야 하는 것" — 정체성 판정, 판타지 배달, 장르 긴장 장치, 레이스 구조.
- 원칙: **버그 수정이 정체성 작업의 지반이다.** 거짓말하는 계기판 위의 극화, 100% 성공 레이드 위의 잭아웃은 헛돈다. 단, docs/21의 전 항목이 선행일 필요는 없다 — 아래 병합 순서는 의존 관계가 실재하는 지점만 교차 배치한다.
