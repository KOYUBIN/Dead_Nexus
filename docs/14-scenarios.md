## 개요

**시나리오**는 기본 게임의 **시작 조건**을 바꿔 매 판을 다르게 만드는 모듈러 변주 시스템. 룰 프레임워크는 그대로, 시작 지점·소수의 룰 오버라이드만 이동한다.

**원칙 (원전 유지)**:
- 표준 11×11 맵에서 모두 플레이 가능 (단, 구현상 S02~S06은 11×11 전용 — 아래 참조)
- 같은 카드·덱·토큰 세트 사용
- 시작 자원·시작 공권력·시작 주가·시작 라운드 변경
- 승리 조건은 유지 (단, 일부 시나리오는 오버라이드·추가 조건 부여)

**웹 구현 프레임워크 (v6.18~)**: 시나리오는 두 종류 모디파이어를 제공한다.
1. **룰 오버라이드** — `SCENARIOS[id][key]`를 사용처에서 `scenarioRule(state, key, fallback)`로 조회 (미지정 시 fallback → 타 시나리오 불변). 예) `startHeat`·`blocAssetBonus`·`mnaNoCooldown`.
2. **initGame 훅** — `applyScenarioInit(...)`/`initGame` 인라인이 시작 players·map을 변형. 예) `allBloc`·`npcFillTo`·`startCredit`·`extraSupport`·`policeStart`.

> 구현 위치: `SCENARIOS` 테이블 = `simulator/v0.5/index.html` 라인 1657~1768. 조회 헬퍼 `scenarioRule` = 라인 1771.

## S02 — 코프 대전 (Corporate War)

**태그라인**: *"두 명만 남으면, 둘 중 하나만 살아남는다."*

**원전 정체성**: 2~3 Bloc 전용. Ghost 없이 블록만 플레이. 내부 M&A 경쟁이 주 갈등. 레이드 없이 주식·구역 싸움으로 수렴. **(유지)**

### 현행 룰 매핑

| 항목 | 원전(v0.5) | 현행(v6.x) 코드 | 비고 |
|---|---|---|---|
| 인원 | 2~3 (전원 Bloc) | `maxParticipants: 3`, `allBloc: true` | 역할 자동 Bloc, Ghost 선택 무시 |
| 시작 공권력 | 3 | `startHeat: 3` | 일치 |
| 시작 크레딧 | +5 | `startCredit: 5` | 일치 |
| 시작 구역 | +1구역 (총 4) | `extraSupport: 1` | HQ 인근 미소유 구역 1칸 추가 |
| NPC 충원 | 5 − 참가 수 | `npcFillTo: 5` | 자동 등락·방어만, M&A 불가 |
| M&A 쿨다운 제거 | ✔ | `mnaNoCooldown: true` | 선언 간 2R 간격 게이트 무시 |
| M&A 승리(2블록 인수) | 즉시 승리 | `euro_checkMnaVictory` → **선언 유예 우회 즉시 확정** | §상호작용 참조 |
| 맵 | 표준 | **11×11 전용** (`maps: ['11x11']`) | M&A는 11×11에서만 활성 |

### 웹 구현 상태 — ✅ 구현 (M&A 각성 시나리오)

### 튜닝값과 근거 (실측 S02 n=50, docs/23 §3)
- 구성상 all-bloc이라 진영 승률 개념 없음(Bloc 0/100). 평균 **10.24R (전 시나리오 최장)**, 자산 경로 82%·**M&A 경로 12%**, 공매도 0.0(Ghost 부재), M&A 선언/판 **1.52**(인수 32/50 — 표준 S01 0.26 대비 각성).
- **v6.19 4중 병목 진단**: 표준 M&A 파라미터로는 자산 루트가 R6에 조기 수렴해 M&A 창이 열리기 전 종료. 4개 레버로 게임을 연장·매집 가속:
  - `blocAssetBonus: 175` — 자산 목표 상향(게임 8~11R 연장 → M&A 창 확보; 측정 튜닝값)
  - `mnaFloat: 3` — M&A 지분 분모 float 하향(기본 10) → 소규모판 51% 게이트 실효화
  - `mnaDesignateCredit: 8` — 목표 지정 ₵ 하한 하향(기본 14) → 1차 인수 후 재지정 허용
  - `mnaSerial: true` — 인수 완료 후 목표 재지정 → 2곳 연속 인수(승리) 경로 개통
  - `mnaBotProb: 1.0` — 봇 M&A 선언 cadence 상향(기본 0.5). **결정적 레버**로 진단됨: M&A 승리 0→14.7%(v6.19 측정).

### No-op·편차 (정직 표기)
- **원전 "주식 거래 라운드당 5주 제한 → 무제한"은 No-op**: 웹 엔진에는 애초에 라운드당 주식 매수 상한이 존재하지 않는다(`BUY_STOCK` 액션에 per-round cap 없음). 따라서 "무제한 거래" 특수 규칙은 구현할 대상이 없음.
- 원전 "Ghost 레이드 불가"는 자명 충족(Ghost 부재 = 레이드 없음).

### 언더독 스케일링
- **제외**. `underdogRelief: false` (v6.25). 의도적 편향(전원 Bloc) 시나리오 → 원전 구성 유지, 언더독 임계 완화를 걸지 않음.

## S04 — 계엄의 밤 (Martial Night)

**태그라인**: *"경찰은 이미 문 앞에 있다. 당신은 이제 시작하는 거다."*

**원전 정체성**: 공권력 최고조. 경찰 NPC 상시 이동. Ghost에겐 지옥, Bloc에겐 단속 계약 기회. **(유지)**

> **구현 이력**: v6.20에는 모바일 NPC 전투 엔진 부재로 **잠금**이었다. v6.21이 NPC 엔티티 엔진(`meta.npcs`: 스폰·이동·Ghost 자동전투)을 구축해 정체성 핵심을 배선하며 해금. v6.23이 구출 퀘스트를 경찰 엔진 재사용으로 배선.

### 현행 룰 매핑

| 항목 | 원전(v0.5) | 현행(v6.x) 코드 | 비고 |
|---|---|---|---|
| 시작 공권력 | **7** | `startHeat: 7` | 일치 |
| 시작 무기 | −2 (압수) | `startWeaponsAll: -2` | 일치 |
| 경찰 NPC 3체 | F3·C6·I6·F9 중 3곳 랜덤 | `policeStart: ['F3','C6','I6','F9']`, `POLICE_COUNT: 3` | 일치 |
| 경찰 이동 | 매R 랜덤 인접 1칸 | **매R 이동 → 가장 가까운 구금 NPC 수호(patrolGuard)** | 방향 보정(아래) |
| 자동 전투 | HP 8, ATK 4 | `POLICE_HP: 8`, `POLICE_ATK: 4` | 일치. 격파 시 렙 +2(`POLICE_KILL_REP`, 원전 무명시→소액) |
| 레이드 성공 공권력 | +2 | `raidHeatBonus: 1` → +1 기본 +1 = **+2** | `scenRaidHeat` 헬퍼 |
| 구출 퀘스트 | 구금 NPC 5명 구출 시 렙 +10 | `captiveStart: 5`, `CAPTIVE_ALL_BONUS_REP: 10` | 개별 구출 렙 +1(`CAPTIVE_RESCUE_REP`, 원전 무명시→소액), 전원 구출 +10 |

### 웹 구현 상태 — ✅ 구현
- **배선 완료**: 경찰 NPC 스폰·이동·자동전투·구출 퀘스트·레이드 heat+2.
- **레거시 챕터 3 연동 (v6.33 배선 완료)**: `legacyUnlockChapter3`(`simulator/v0.5/legacy_module.js`)가 이번 판의 계엄 발생 신호(`martialLaw` — 공권력 최고조/경찰 전개/S04 플레이)를 파생해 자동 해금한다. S04 플레이 = 조건 정의상 martialLaw 충족 → 자동 해금(원전 "공권력 트랙 10 도달"과 동치). 종전 "미배선" 상태는 v6.20 시점 기록이며 v6.33에서 해소됐다.

## 상호작용 — 시나리오 특수 룰 × v6.x 신규 시스템

원전 작성 이후 게임 코어에 6개 대형 시스템이 도입되며, 시나리오 특수 룰과 만나는 지점이 생겼다. 아래는 **웹 코드가 실제로 처리하는 방식** 기준(코드 확인 후 기술, 애매하면 (추정)).

### 1) 종료 선언 라운드 (v6.12) × 자산/렙 승리
- **변경**: 원전은 "자산 60 / 렙 25 도달 = **즉시 승리**"였으나, v6.12부터 자산·렙 경로는 즉시 승리가 아니라 **📢 선언 → 유예 1R → 유지 시 확정**. 5R 가드(R5 이전 판정 없음)로 R5 즉사 해소. 같은 플레이어 게임당 2회 캡, 이탈 시 해제·재선언 가능. (`checkInstantVictory`/`applyVictoryDeclaration`, 라인 6216·6250)
- **시나리오 영향**: 원전의 모든 "즉시 승리" 서술은 "선언 → 유예 1R 확정"으로 읽어야 함(S03 렙25·S05 자산75 등). 유예 라운드 동안 봇 Ghost는 선언자를 최우선 레이드 타겟(+6·+10 가중)으로 삼는다.
- **예외 — 즉시 확정**: **M&A 2블록 인수(S02)**·NEXUS 연속 점유는 "이벤트형 즉시 승리"로 선언 유예를 **우회해 즉시 확정**(`euro_checkMnaVictory`, 5R 가드도 이전). S02의 M&A 승리는 여전히 즉발.
- **`blocAssetBonus`의 의미**: S02(175)·S03(80)·S05(25)·S06(30)의 자산 목표 상향은 곧 **선언 도달을 지연**시켜 게임을 연장하는 레버 — 종료 선언 시스템과 직접 맞물린다.
- **역전 실측**: 선언 라운드는 100% 작동하나 실제 역전은 1.4%(4/278)에 그침 — '지켜보는 종결'에 가까움(docs/23 §4).

### 2) S05 8R 타임리밋 × 종료 선언
- `roundLimit: 8` 초과(newRound > 8) 시 `checkVictoryByPoints`가 **최고 자산 Bloc / 최고 렙 Ghost를 자동 승리** 처리(라인 3703). 이는 종료 선언 유예와 **별개의 하드 타임아웃** — 8R 내에 선언 확정이 나면 그것으로 끝나고, 안 나면 8R 도달 시 점수 최고자 자동 승리.
- 실측 S05 시간종료 경로 28%(docs/23) — 스프린트 압박이 실제로 발현.

### 3) 공매도 (v6.13) × S06 거래 동결·붕괴
- 공매도는 **전 시나리오 상시 기능**(`SHORT_CONFIG`: 계약 ₵4, 블록당 상한 2·총 상한 3, 하락 1pt당 ₵2 정산).
- **S06 거래 동결(`tradeFreezeRounds: 2`)**: 첫 2R은 매수·매도·**숏 진입 전부 금지**(R≤2), R3 재개. 웹 UI가 "🧊 시장 동결" 배지로 표기(라인 7979). 동결 해제 후 공매도가 붕괴 저가에서 실효.
- **S06 저가 정산 2배(`shortLowPriceMult`)**: 정산 시점 종가가 ≤5인 블록은 숏 정산 ₵ 2배. 뉴스 하락 +50%(`newsStockDownMult: 1.5`)와 결합해 붕괴가 유지·심화되면 Ghost 숏 차익이 증폭.

### 4) 덱 오염 (v6.14) × S06 스캔들 선삽입
- base 게임: 상처(Ghost HP 50% 교차)·스캔들(Bloc 구역 상실/M&A 실패) discard 삽입, 상한 2·봇 −1000점 회피로 스파이럴 방지.
- **S06 `startScandalEach`**: 시작 시 전 블록 덱에 스캔들 1장 선삽입 → base 오염 사슬과 합류. 붕괴 초반부터 Bloc 덱이 오염된 상태로 출발.

### 5) 모바일 NPC 엔진 (v6.21) × S04
- `meta.npcs` 엔티티 배열: 경찰 3체(HP8·ATK4)·구금 5체 스폰. 경찰은 매R 이동하며 `patrolGuard`로 가장 가까운 구금 NPC를 수호. Ghost가 경찰 구역 진입 시 자동전투(`applyDamage` 재사용), 격파 시 렙 +2. Ghost가 구금 NPC 구역 도착 시 자동 구출(★+1, 전원 5 구출 시 +10).
- **저활성 주의**: 봇 AI가 구출·격파를 목표화하지 않아 실측 발화율 낮음(§S04 참조).

### 6) 언더독 스케일링 (v6.25) × 시나리오 게이팅
- `euro_underdogGoalScale`: 진영 인원 불균형 시 열세 진영 승리 임계를 완화(소수 진영 승률 0.7~17%→37~51%로 교정, v6.25 커밋). 2:2 bloc 94% 교차 시너지 발견이 계기.
- **게이팅**: `scenarioRule(state, 'underdogRelief', true) === false`면 항등 폴백(라인 1587). **S01만 적용**(키 미지정 → true), **S02~S06 전부 `underdogRelief: false`** — 의도적 편향 시나리오의 개성을 보존하기 위해 언더독 완화를 걸지 않음.

1. 시작 공권력: 0~10
2. 시작 주가: 5~15 (모두 동일 or 블록별)
3. 시작 자원: 표준 ±50%
4. 승리 조건: 자산 ±30% / 렙 ±50% / 레이드 ±1
5. 플레이 시간: 6~15라운드
6. 특수 규칙 1~2개

공식 시나리오를 참고해 실험. 재미있는 커스텀은 Notion DB에 기록·공유.
