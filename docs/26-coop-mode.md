# 26. 협동 시나리오 모드 — INCURSION (v6.55)

> **한 줄 요약**: 정령섬·엘드리치 호러류 "시나리오 깨기" 형식의 시뮬 협동 모드.
> 전 좌석이 한 팀(인간 1~4 + 아군 봇)이 되어, **공표된 결정론 시간표**대로 상륙하는
> MERIDIAN 잔당·청산관리단을 파멸 트랙(RECEIVERSHIP)이 차기 전에 저지한다.

## 1. 설계 개요

### 1.1 형식 번역 — 정령섬 침략자 단계의 DEAD NEXUS 화

| 정령섬 원형 | INCURSION 번역 | 구현 |
|---|---|---|
| 침략자 카드 단계 (탐사→건설→약탈) | **상륙 시간표** — 어느 구역에 몇 R에 상륙하는지 셋업에서 전부 공개 | `coopLandings` 리터럴 (S07 BLACKOUT_ORDER 선례, Math.random 0회) |
| 황폐화(Blight) 트랙 | **파멸 트랙 (RECEIVERSHIP 게이지)** 0→상한, 도달 = 즉시 팀 패배 | `meta.coop.doom` + `coopDoomCap` |
| 침략자 도시/마을 | **MERIDIAN 거점** (회수반 거점 ⛓ / 압류 집행소 🧾 / 청산인 지휘 거점 ⚖) | `meta.coop.bases` |
| 정령의 힘 (비대칭 협동) | **Ghost = 강습**(거점 파괴), **Bloc = 경제·장부 방어**(파멸 억제) | `coop_assault` / 자동 안정화 |
| 시나리오 카드 | C01/C02/C03 — 별점 1~3★ + 해금 체인 | `COOP_SCENARIOS` + `dn_coop_v1` |

### 1.2 세계관 계보 — 3트랙 교차 (RPG Act 2~3 정본의 시뮬 역수입)

- **[계승 rpg/data/missions/a2-00·a2-99]** MERIDIAN = 외부 기업 "연합" 침공군. 기함 격침
  후의 **잔당**이 C01·C02 의 침공 유닛이다.
- **[계승 rpg/data/missions/a3-00-framing]** "연합이 무너지면 남는 건 시체가 아니라 **채권**"
  — 청산관리단은 장부·담보·회수 절차로 도시를 가져간다. 파멸 트랙 이름
  *RECEIVERSHIP(관리권 인도)* 은 이 전제의 직역. Bloc 의 파멸 억제 액션 이름도 "장부 방어".
- **[계승 rpg/data/missions/a3-03-finale]** "도시를 빼앗는 데 함대는 필요 없다. 필요한 건 서명
  하나" — C03 정산일의 기함급 지휘 거점(LIQUIDATOR)은 a3-03 결전의 시뮬 호응. 패배 문구
  "이의 제기 창구: 없음" 도 a3-03 STORY_CARD 인용.
- **[계승 rpg/data/enemies.js]** MERIDIAN_ASSESSOR(🧾)/COLLECTOR(⛓)/LIQUIDATOR(⚖) 명칭.
- **[계승 lore_module GHOST_IDENTITY.BROKER]** SILK("장부를 쥔 중개인") — 승리/패배 에필로그 화자.
- **[신규]** 협동 모드 자체(전 좌석 한 팀·비대칭 기여) · 파멸 트랙 · 별점 · `dn_coop_v1` 전적 ·
  C03 해금 체인 · 강습/안정화/오염 룰.

### 1.3 아키텍처 — coop_module.js 외장 (인라인 500,000자 임계 대응)

## 2. 공통 룰 (전부 셋업 화면에 공표 — 정보 은닉 없음이 이 모드의 정체성)

### 2.1 좌석
- 4석 고정 = 인간 1~4 + 아군 봇 충원 (목표 구성 **2👻+2🏢**, 충원 순서 결정론:
  Ghost BLADE→RIGGER→CIPHER→… / Bloc IRONWALL→CARBON→VANTA→…).
- 솔로 협동(인간 1)·핫시트 협동(인간 2~4, pass-device 흐름 재사용) 모두 지원. NPC 좌석 0.

### 2.2 침공 (라운드 훅 `coop_advance`, NEXT_ROUND 말미 — 처리 순서 고정)
1. **주둔 강습** — 활성 거점 셀 또는 4방 인접("포위 강습")에 서 있는 Ghost 는 자동 강습 1회.
2. **목표 완수 체크** — 완수 시 즉시 팀 승리.
3. **유지 파멸** — 생존 거점당 `coopDoomPerBase` 가산 (상륙 라운드 내 즉살 = 유지 비용 0 보상).
4. **상륙** — 시간표의 이번 라운드분. 동일 좌표 활성 거점 존재 시 스킵.
   상륙마다 `coopDoomOnLand` 가산. 점거 셀 `merBase` + 4방 인접 `merTaint→merDark` 표기.
5. **Bloc 장부 방어(자동)** — 파멸>0 이면 좌석당 R1회 ⚙`coopStabCost` 자동 지불 → 파멸 −1.
   (자동인 이유: docs/14 §S04 교훈 — 봇이 목표화하지 않는 선택 액션은 죽은 콘텐츠가 된다.
   S07 복구 자동화 선례.)
6. **파멸 상한 체크** — `doom ≥ coopDoomCap` → 즉시 팀 패배 (☠ RECEIVERSHIP).

### 2.3 점거·오염 (표시 = 판정: 셀 플래그 단일 소스 — S07 `cell.blackout` 선례)
- 거점 셀(`merBase`) + 4방 인접(`merDark`) → **구역 수입 0** (COLLECT_INCOME 이 셀 플래그를
  직접 읽음). 거점 파괴 시 `coop_refreshCells` 가 활성 거점 집합에서 전량 재계산.

### 2.4 강습 (기존 레이드 판정 성분 재사용 — d6 없음 = 완전 결정론·판정식 공개)
```
강습 총합 = raidBonus(무기 기반, 3+min(3,⌊무기/3⌋)+장비) + ATK + 전투 트랙 보너스
성공: 총합 ≥ 거점 방어  →  피해 1 (+1 if 총합 ≥ 방어+4) · ★+2 (파괴 시 +3, 기함 +6) · 파괴 시 파멸 −coopKillDoom
실패: HP −1 (경쟁 레이드 −3 대비 완화 — 협동 리트라이 페이싱)
```
- 발동 채널 ①주둔(라운드 종료 자동, 좌석당 1회) ②atk 카드(거점 사거리 안에서 즉시 추가 강습
  으로 **변환** — `coop_effectFilter`) ③최종 라운드 정산(`coop_timeUp` 내).
- 강습에는 현상수배·공권력 부작용 없음 (점령군을 치는 것은 도시의 편).

### 2.5 협동 게이트 (전 좌석 한 팀 계약)
| 금지 축 | 게이트 지점 |
|---|---|
| PvP 레이드·Ghost 결투 (이동 트리거) | 이동 효과의 `_coopPvpOff` 게이트 |
| 적대 M&A | `euro_declareMnaCheck` 최상단 거부(사유 표기 — 인간 UI·봇 공용) |
| 아군 견제 | `euro_grantSuppression` 항등 + `HUMAN_SUPPRESS` 무발동·사유 로그 |
| 적대 카드 효과 (청부·현상금·주가 공격·mini-raid 등 51키) | `coop_effectFilter` 가 효과 객체에서 제거 (자기강화 반쪽은 보존) |
| 개인(경쟁) 승리 | `evalPlayerVictory` 협동 시 null → 종료 선언·즉시 승리 경로 자체가 없음 |

### 2.6 아군 봇 조준 (rules_botGoalGap 선례 — 시나리오 목표 함수에서 파생)
- **이동 목표**: `coop_botGhostGoal` — 활성 거점의 **분담 배정**(좌석 오름차순 그리디, 최근접
  미배정 거점; 동률 좌표 사전순 = 결정론). 거점 전멸 시 현위치 유지.
- **카드 선택**: `coop_scoreGhost/Bloc` — 적대 반쪽 −15(무력화돼 낭비), Ghost 는 이동
  +10·atk +4(강습 연료), Bloc 은 경제 +6(⚙ = 안정화 연료).
- **반쪽 선택**: `coop_botHalves` — 봇 Ghost 의 기본 반쪽(1번=top·2번=bot 고정)을 거점에서
  멀면 move 반쪽, 사거리 안이면 atk 반쪽으로 교체.
  (측정 근거: 고정 반쪽 탓에 BLADE 봇이 7R 를 제자리 소모하는 트레이스 관측 → 교정.)

### 2.7 별점·전적 (판정식 공개)
- `★1 = 클리어` / `★2·★3` 은 시나리오별 데이터(§3 표). 판정 시점 = 승리 확정 라운드.
- localStorage `dn_coop_v1` = `{ scens: { C01: { best, clears, plays } } }` (기기 로컬, 실패 무해).
- **C03 해금 = C01 클리어 ≥1 && C02 클리어 ≥1** (셋업 UI 잠금 — 헤드리스 측정은 비관여).

## 5. 품질 계약 이행

1. **기존 모드 무손상**: 협동 외 시나리오에서 coop 전 진입점이 인자 state 를 참조 동일로
   반환 — 유닛 "격리" 6종이 핀. 기존 563 유닛 전부 유지 (총 **629**, ×3회 ALL PASS).
2. **표시 = 판정**: 파멸 트랙·목표 진척·별점·HUD 다음 상륙 전부
   `coop_doom/coop_objective/coop_stars` 단일 소스 파생 — 유닛 핀.
3. **조용한 실패 금지**: coop_module 미로드 시 협동 카드 비활성 + 사유 문구, E13 MODULES
   목록에 `['coop_module.js','coop_active']` 등재(배너·콘솔 고지).
4. **결정론**: 시간표·강습·파멸·안정화·봇 조준 전 경로 Math.random 0회 (모듈 내 사용 없음,
   유닛 "동일 입력 2회 → 동일 결과" 핀).
