🎲 레이드 판정 공식

threshold = 5 + 방어토큰 (요새🏰 / 주둔👮 / 베일🛡 각 +1)
· 인간: d6 + 투자스탯(atk/spd/hack) + 카드보너스 ≥ threshold → 성공
· 봇·카드 레이드: 주사위 없음(결정론) — raidBonus[3 + 무기÷3(최대+3)] ≥ threshold
· 성공 시 보상 결정: ★평판 vs ₵+⚙약탈 택1 (기본=평판)

🏆 승리 조건

👻 Ghost (독립) — 둘 중 하나
  • 전투 루트: 평판 ≥ 42(5×5) / 45(11×11) + 레이드 ≥ 2회
  • 단독 루트: 평판 ≥ 60(5×5) / 70(11×11) (레이드 무관)
🏢 Bloc (메가기업) — 자산 도달
  • 자산 ≥ 73(5×5) / 100(11×11) — 인원 보정: 3인 −1 / 2인 −2
  • 자산 = 자기자본 + 주식(자기주가 제외) + NEXUS 점유 보너스
  • NEXUS 점유 시 자기 룰 활성 (CARBON: 자사 구역 수입 +1 등)
  • 선언 → 유예 1R → 확정 (즉시 아님, 아래 종료 선언 참조)
  • M&A 인수 루트는 테이블 v1 미포함 → v2 (아래 박스)

⚙ 핵심 숫자

맵 5×5 (튜토리얼) / 11×11 (정식) · 라운드 평균 5~7R · 손패 6장 시작 · 계획 라운드당 2장
트랙 5개 × LV 1~5 · Cyberware 게임당 2개 (R3/R6) · 하이라이트 12종 (게임당 1회씩)

✅ 테이블 v1 수기 정본 절차 (docs/24 감사 ✅)

📢 종료 선언 (자산·평판 경로)
  • 승리 임계 도달 = 즉시 승리 아님
  • 도달자 선언 → 라운드 트랙에 📢 마커
  • 유예 1R 진행 (전원이 지켜봄)
  • 유예 후에도 조건 유지 → 확정 승리
  • 이탈 시 해제, 재도달 시 재선언 (같은 플레이어 게임당 2회 캡)
🃏 덱 오염 (상처 · 스캔들)
  • 상처: HP 임계 교차 시 자기 discard에 1장 삽입
  • 스캔들: 레이드로 구역 상실 · 스캔들 뉴스 시 삽입
  • 오염 카드 = TOP/BOT·MAIN/SIDE 모두 무효 (손에 오면 낭비)
  • 물리 카드로 실삽입 — 게임당 상한 2장
⚔ 상성 · 이니셔티브 · 트랙
  • 상성: 진영 카드 아이콘 이중 사이클 +2 / +1 (조회 불필요)
  • 이니셔티브: init(=TL×10 정렬) 낮은 값부터 실행
  • 수배·공권력(heat): 0~10 트랙 + 큐브 1개 (10 도달=계엄/종료)
  • 거리명성 = 5트랙 LV 합. LV2 패시브 / LV4 강화 / LV5 1회 능력
