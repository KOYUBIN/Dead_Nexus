### 2.1 B-01 근거 갱신 — S03 2-레버 스윕 전수 측정 (v6.46 / 66차)

v6.20의 "단일 레버 공집합"에 남아 있던 잔여 질문(**2-레버 조합 미측정**)을 전수 측정으로 닫는다.
측정: `sim-e2e/run.js` 11×11 S03 · **셀당 n=300** · 총 14셀 · 에러 0 · 레버는 `DN_SCEN_OVERRIDE`
in-page 오버라이드(레포 기본값 무변경).

**지정 그리드 — `blocAssetBonus` × `ghostRepBattleOverride`** (ghost% / avgRound):

| | rep 25 (현행) | rep 27 (+2) | rep 28 (+3) |
|---|---|---|---|
| **bab 80 (현행)** | **62.0% / 7.65** (기준선) | — | — |
| bab 90 | 64.0% / 7.62 | 63.3% / 7.67 | 63.7% / 7.58 |
| bab 100 | 69.0% / 7.82 | 67.7% / 7.64 | 72.3% / 7.71 |
| bab 110 | 71.3% / **7.91** | 71.0% / 7.73 | 73.0% / 7.78 |

→ **수용역(ghost ≤ 70 ∩ avgR ≥ 8) 해 없음 — 공집합.** 9셀 최대 avgR 은 7.91(bab110/rep25)이고
그 셀의 ghost 는 71.3%로 상한 초과. avgR ≥ 8 을 만든 셀은 **하나도 없다**(±0.19, 95% CI).
**결론: 기각 — 코드 무변경.**

**왜 공집합인가 (레버 감도 진단, 보충 측정 n=300):**

| 조합 | ghost% | avgR | 해석 |
|---|---|---|---|
| bab110 / **rep 35** / raids 3 | 71.7% | 7.80 | 렙 임계를 **+10** 올려도 기준선과 무차이 → **렙 게이트는 비구속(inert)** |
| bab 80 / rep 25 / **raids 4** | 30.0% | **8.71** | 레이드 게이트 1단 상향만으로 avgR 밴드 진입 |
| bab 100 / rep 25 / **raids 4** | 32.7% | **9.06** | |
| bab 110 / rep 25 / **raids 4** | 34.7% | **9.35** | |

- Ghost 승리의 지배 경로는 `repBattle`(렙 ≥ 25 **∧** 레이드 ≥ 3)인데, 봇 Ghost 는 레이드 3회를
  채우기 훨씬 전에 렙 25를 초과한다. 즉 **이 연언(∧)에서 실제로 구속하는 항은 레이드 횟수**이고
  렙 임계는 여유항이다. `ghostRepBattleOverride` 를 어떻게 움직여도 게임 길이가 변하지 않는 이유.
- 반대로 `ghostRaidsOverride` 3→4 는 단독으로 avgR 을 7.65 → 8.71 로 올린다. 다만 같은 조작이
  ghost 를 62% → 30% 로 **반전**시킨다 — docs/14 §S03 밸런스표의 정체성("Ghost 압도 ●●●●●")과
  충돌하고, 원전 명시값(**Ghost 승리 레이드 3회**)을 바꾸는 일이라 **시뮬 트랙 단독으로 채택하지 않는다.**
- 또한 수용 기준 `ghost ≤ 70` 에는 **하한이 없어서**, 문자 그대로는 ghost 30%/avgR 8.7 도 "충족"으로
  읽힌다. B-01 을 실제로 닫으려면 기준을 `ghost ∈ [50, 70] ∩ avgR ≥ 8` 같은 **양측 밴드**로
  재정의하는 편이 정직하다 (제안).

**회귀 게이트(동일 빌드)**: S01 11×11 n=300 → ghost 46.7% (밴드 40~60 유지) · avgR 8.38 · 에러 0.
유닛 320/320 PASS. 측정 훅은 `sim-e2e/run.js` 의 `DN_SCEN_OVERRIDE`(JSON) — in-page 오버라이드라
레포 기본값은 전 셀에서 무변경이며, 미지정 시 분기 자체를 타지 않는다(기존 측정과 동일 경로).

**다음 액션(설계 결정 필요, 시뮬 트랙 범위 밖)**: docs/14 §S03 의 "Ghost 승리 레이드 3회"를
유지할 것인가. 유지 시 B-01 은 **의도된 구조적 특성**(짧고 Ghost 우세한 시나리오)으로 클로즈,
변경 시 raids 4 + `blocAssetBonus` 재튜닝으로 밴드 진입이 가능하다(위 표가 후보값).
